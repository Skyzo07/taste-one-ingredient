One ingredient, one picture: a giant cut **lemon** — glistening segments, a bitten wedge, juice in the air — drawn pixel by pixel in pure Node.js. No assets, no network, no image libraries: `main.ts` builds the whole 1024×1024 picture from code (own pixel buffer, own PNG writer with posterised colours and Bayer dithering) and writes it to `/output/entry.png`. Sour you can see.

## Run it

```sh
node main.ts
```
