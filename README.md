The picture that tastes of one ingredient: LEMON. A giant cut lemon half,
cut face to the viewer, on deep leaf green — eight glistening segments with
cream membranes and a star core, glossy yellow rind, two green leaves, a
small bitten wedge with juice flying off it, and the word LEMON at the
bottom. Rendered by a small deterministic Node program (stdlib only) with
its own pixel buffer and PNG writer — no dependencies, no randomness
beyond a fixed seed.

## Run it

```sh
node main.ts
```

This writes a 1024×1024 PNG to `/output/entry.png`.
